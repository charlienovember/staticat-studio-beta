# Staticat Studio Pro beta

Beta builds of Staticat Studio Pro for testers, and the update feed the app checks.

Testers start at the [download page](https://charlienovember.github.io/staticat-studio-beta/): the beta terms, the
latest build and how to open it the first time. Once it is installed, the app tells you when a newer build is out
(Staticat Studio Pro › Check for Updates…).

The page's source is in the app's repository (`docs/beta-site`); change it there.
